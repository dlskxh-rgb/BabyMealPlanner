# 🍽️ BabyMealPlanner

A simple meal planning and food tracking web application for parents.

## 📌 About the Project

BabyMealPlanner helps parents keep track of their child's daily meals, manage available ingredients, and save important allergy notes.

The application works directly in the browser without requiring an account or a server.

## ✨ Features

- 📝 Track daily meals
- 🗑️ Remove meal items
- ⚠️ Save allergy notes
- 🥕 Manage available ingredients
- 💡 Get random meal ideas
- 💾 Save data using LocalStorage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
