🍽️ BabyMealPlanner


A simple meal planning and food tracking web application for parents.


📌 About the Project


BabyMealPlanner helps parents keep track of their child's daily meals, manage available ingredients, and save important allergy notes.


The application works directly in the browser without requiring an account or a server.


✨ Features




📝 Track daily meals


🗑️ Remove food items


⚠️ Save allergy notes


🥕 Manage available ingredients


💡 Get random meal ideas


💾 Save data using LocalStorage




🛠️ Technologies Used




HTML5


CSS3


JavaScript


LocalStorage

🚀 Getting Started




Clone or download this repository.


Open index.html in your web browser.




No additional installation is required.


💾 Data Storage


This project uses the browser's LocalStorage API.


Your meal records, ingredients, and allergy notes are stored locally in your browser.
